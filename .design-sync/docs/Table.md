# Table

Tabela semantica, com `<table>` de verdade.

Compoe com `TableHeader`, `TableBody`, `TableRow`, `TableHead` e `TableCell`.

`selected` na linha marca no `aria-selected` e desenha uma barra de acento na
lateral. Cor sozinha nao e estado.

A moldura rola de lado sozinha, entao tabela larga nao empurra a pagina.
