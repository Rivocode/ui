# Pagination

Navegacao entre paginas de uma listagem.

A lista de numeros encolhe sozinha, entao ela ocupa a mesma largura com dez ou
com dez mil paginas. No celular os numeros somem e ficam so as setas com "3 de
12": alvo de 32px erra o vizinho, e quase sempre se quer a proxima.
