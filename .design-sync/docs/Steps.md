# Steps

A regua de passos de um formulario longo. Anda junto com o `useWizard()`.

No celular vira uma linha de texto com barra de progresso: quatro bolinhas com
rotulo em 390px viram quatro palavras cortadas, e o que importa ali e saber
quanto falta.

So da para voltar, nunca pular para frente.
