# EmptyState

Estado vazio, com saida.

`title` e `description` sao obrigatorias, e `action` e fortemente recomendada.
Uma tela que so diz "nenhum resultado" empurra para a pessoa o trabalho de
adivinhar o que fazer.

Distinga os dois vazios: primeiro uso ("emita a primeira nota") pede acao de
criacao; busca sem resultado ("nada para esse filtro") pede acao de limpar
filtro.
