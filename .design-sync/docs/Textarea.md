# Textarea

Campo de varias linhas. Passa pelo `Field.Control` da Base UI como o `Input`,
entao rotulo, ajuda e erro se ligam sozinhos dentro de um `Field`.

Nao tem variante de tamanho: altura aqui e numero de linhas, e misturar isso com
a escala de controle criaria um `lg` que nao quer dizer nada.
